TP1 : Installation et Configuration d'un Serveur DHCP

Auteur : Lucas Lestiennes Module : TC4

1. Introduction au service DHCP

Le protocole DHCP (Dynamic Host Configuration Protocol) est essentiel pour l'automatisation de la configuration réseau. Un serveur DHCP attribue dynamiquement aux clients :

  • Une adresse IP unique.
  • Un masque de sous-réseau.
  • L'adresse de la passerelle par défaut.
  • Les adresses des serveurs DNS.

Pour ce TP, nous utilisons deux machines virtuelles sous VirtualBox (Windows Server 2022 pour le serveur, Windows 11 pour le client), configurées en "Réseau Interne".

2. Configuration de l'Étendue (Scope)

2.1 Plage d'adresses et Exclusions

Nous définissons l'étendue des adresses que le serveur peut distribuer. Pour réserver des adresses à des serveurs ou des imprimantes (adressage statique), nous configurons des exclusions.

![[{F945586C-2D5F-4210-9400-7756E48ABF82}.png]]

  • Exclusion : On définit une borne de début et de fin. Ces adresses ne seront jamais distribuées par le DHCP.

2.2 Gestion du Bail (Lease)

Le bail est la durée de validité de l'adresse IP accordée au client. À l'expiration du bail, le client doit renouveler sa demande.

3. Options et Réservations

3.1 Options d'étendue

Le DHCP permet de pousser des paramètres supplémentaires, notamment la passerelle par défaut (Router) indispensable pour sortir du sous-réseau local.

3.2 Réservation d'IP

Pour certains postes nécessitant une IP fixe mais gérée de manière centralisée, on utilise la réservation. L'adresse IP est liée à l'adresse MAC de la carte réseau du client.

4. Validation du Fonctionnement

Une fois le service configuré et activé, nous vérifions que le client Windows 11 reçoit bien sa configuration. La validation finale se fait par des tests de connectivité (Ping) entre le client et le serveur.
