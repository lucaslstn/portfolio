Auteur : Lucas Lestiennes Module : TC1

Tâche 1 : Conception du Réseau

1.1 Documentation Technique

L'objectif est de définir un plan d'adressage cohérent pour une infrastructure comprenant :

  • Routeur : 1
  • Switchs : 22
  • Postes clients : 380

Plan d'Adressage IP

Réseau @ Réseau / Masque Plage Utilisable Passerelle Plage Serveurs
DGSA 10.0.0.0 / 8 10.0.0.1 - 10.255.255.254 10.0.0.201 10.0.0.202 - 10.0.0.254
PROD 172.16.0.0 / 16 172.16.0.1 - 172.16.255.254 172.16.0.201 172.16.0.202 - 172.16.0.254
SEXT 192.168.0.0 / 24 192.168.0.1 - 192.168.0.254 192.168.0.101 192.168.0.202 - 192.168.0.254

Plan de Nommage

  • Routeur : PRIN-ROUT-001
  • Switchs : [NOM_RESEAU]-SWTH-[NUM]
  • PC : [NOM_RESEAU]-PC-[NUM]

Tâche 2 : Implémentation Statique sous Packet Tracer

Mise en place de la topologie et configuration manuelle des premières interfaces pour valider la connectivité.

Exemples de configuration :

  • DGSA-PC-001 : IP 10.0.0.1
  • PROD-PC-001 : IP 172.16.0.1
  • SEXT-PC-001 : IP 192.168.0.1

Tâche 3 : Analyse du Fonctionnement

Tests de connectivité (ICMP)

  • Intra-réseau : Un ping entre DGSA-PC-001 et DGSA-PC-002 est immédiat car ils partagent le même domaine de diffusion.
  • Inter-réseaux : Un ping entre PROD-PC-004 et SEXT-PC-002 nécessite le passage par le routeur.

Tâche 4 : Passage à l'Adressage Dynamique (DHCP)

Configuration des pools DHCP sur les serveurs de chaque réseau pour automatiser l'attribution des adresses.

Validation de l'attribution

Les captures montrent que chaque client reçoit désormais son IP, son masque, sa passerelle et son serveur DNS de manière dynamique.

Récapitulatif des baux DHCP :

  • DGSA-PC-001 : 10.0.0.1 / DNS: 10.0.0.202 / GW: 10.0.0.201
  • PROD-PC-001 : 172.16.0.1 / DNS: 172.16.0.202 / GW: 172.16.0.201
  • SEXT-PC-001 : 192.168.0.1 / DNS: 192.168.0.202 / GW: 192.168.0.201
