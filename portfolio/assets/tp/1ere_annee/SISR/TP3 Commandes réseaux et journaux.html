TP3 : Commandes réseaux et journaux d'activité

Auteur : Lucas Lestiennes Module : SISR (R2)

Étape 1 : Diagnostic d'incident système

Contexte : Le responsable du réseau informatique de la société GSB demande de lister les commandes utiles au diagnostic d'incident système sous Windows et Linux.

Liste des commandes à analyser

  • ping
  • netstat
  • nmap (optionnel)
  • ipconfig / ifconfig (Linux)
  • net (optionnel)
  • netsh (optionnel)
  • nslookup
  • dig (optionnel)
  • arp
  • tracert / traceroute
  • nbtstat (optionnel)
  • ip (commande Linux iproute2)

Travail à faire

  1. Compatibilité : Préciser pour chaque commande si elle est utilisable sous Linux, Windows ou les deux.
  2. Options : Explorer les options intéressantes pour chaque commande.
  3. Analyse approfondie du Ping : Détailler la commande ping et analyser ses différents résultats possibles.

Étape 2 : Questions spécifiques

Répondre aux questions suivantes :

  1. Ping continu (Windows) : Quelle option permet d’envoyer des paquets de façon continue ? Quelle est son utilité ?
  2. Netstat : Quelle option permet d’afficher les connexions actives et les ports ouverts sur la machine ?
  3. Table de routage : Quelle instruction permet d’afficher la table de routage locale ?
  4. Cache DNS (Windows) : Quelle instruction permet de vider le cache DNS local ?
  5. Résolution inverse : Quelle instruction permet de trouver un nom de domaine à partir d'une IP ?
  6. Service Station de travail : Quelle instruction permet de vérifier si ce service est actif localement ?
  7. NetBIOS : Quelle instruction affiche la table des noms NetBIOS résolus localement ? (Quelle différence avec un nom DNS ?)
  8. Serveur DHCP : Quelle instruction permet d’identifier le serveur DHCP qui a attribué l’adresse IP ?

Note : Certaines commandes Linux peuvent nécessiter l'installation du paquet net-tools (sudo apt-get install net-tools).

Étape 3 : Journaux d'activité

Objectif : Analyser l'activité d'un ordinateur via les journaux système sous Windows et Linux.

Travail à faire (sous forme de tableaux)

Pour les deux systèmes d'exploitation, préciser :

  1. Localisation : Où trouver ces journaux ?
  2. Pluralité : Y a-t-il plusieurs journaux ?
  3. Rôles : Quel est le rôle de chacun ?
  4. États : Quels sont les états possibles pour les événements ?
  5. Sauvegarde : Comment sauvegarder/exporter ces journaux ?
