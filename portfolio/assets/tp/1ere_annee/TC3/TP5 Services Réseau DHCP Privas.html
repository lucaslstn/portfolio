TP5 : Services Réseau - DHCP et DNS (Étude de Cas Privas)

Auteur : Lucas Lestiennes Module : TC3

1. Test d'Accès au Site Intranet

L'objectif est de vérifier l'accès au portail www.ent.aerius.fr depuis différents postes de travail.

Résultats des tests initiaux

Réseau Poste Résultat Observation
Marketing PCM2 OK Accès réussi au portail.
Marketing PCM1 ÉCHEC Aucune réponse.
Administratif PCA1 OK Accès réussi au portail.
Administratif PCA2 ÉCHEC Aucune réponse.

2. Diagnostic des Dysfonctionnements

L'analyse de la configuration IP des postes en échec révèle des anomalies critiques :

Poste IP Passerelle (GW) DNS Problème identifié
PCM1 192.168.7.1 192.168.7.116 192.168.7.193 Mauvaise passerelle (devrait être .126).
PCA2 192.160.7.130 192.168.7.190 192.168.7.191 Erreur d'IP (160 au lieu de 168) et mauvais DNS (.191 au lieu de .193).

Recommandations de configuration

Pour que tous les postes fonctionnent, les paramètres suivants doivent être appliqués via le serveur DHCP :

  • Service Marketing : GW = 192.168.7.126 / DNS = 192.168.7.193
  • Service Administratif : GW = 192.168.7.190 / DNS = 192.168.7.193

3. Résolution d'Incidents DNS

Un second test sur l'URL www.gcom.aerius.fr a échoué sur tous les postes (Erreur : Host Name Unresolved).

Analyse du problème : Le diagnostic s'est porté sur le serveur DNS central. Une erreur de saisie a été identifiée dans la table de résolution du serveur aerius : l'entrée DNS pointait vers aerus.fr au lieu de aerius.fr.

Action corrective : Après correction de la faute de frappe dans le service DNS du serveur, l'accès au site gcom est redevenu fonctionnel pour l'ensemble du parc.
