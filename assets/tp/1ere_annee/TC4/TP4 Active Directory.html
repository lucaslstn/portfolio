TP4 : Introduction à Active Directory

Auteur : Lucas Lestiennes Module : TC4

1. Mise en place du Serveur

L'implémentation d'un annuaire Active Directory commence par l'installation d'un serveur sous Windows Server 2022.

1.1 Prérequis

Avant de promouvoir le serveur en contrôleur de domaine (DC), il est nécessaire de :

  1. Assigner une adresse IP statique au serveur.
  2. Donner un nom explicite à la machine (ex: SRV-AD-01).

2. Installation du Rôle AD DS

Le rôle AD DS (Active Directory Domain Services) est installé via le Gestionnaire de serveur.

(Détails de l'installation et captures de configuration)

3. Promotion du Contrôleur de Domaine

Après l'installation du rôle, le serveur doit être promu pour créer une nouvelle forêt et un nouveau domaine (ex: 148.sio).

Note : L'octet 148 est utilisé conformément au plan d'adressage du projet.
