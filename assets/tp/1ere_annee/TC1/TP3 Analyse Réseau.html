TP3 : Analyse et Diagnostic Réseau

Auteur : Lucas Lestiennes Module : TC1

1. Analyse de l'Architecture Réseau

Typologie

  • Taille : Le réseau est constitué de deux réseaux locaux (LAN) interconnectés par des routeurs, formant une structure étendue (WAN).
  • Topologie : C'est une topologie en étoile, où les périphériques finaux sont connectés à un point central (switch ou concentrateur).
  • Type d'accès : Il s'agit d'un Intranet, un réseau privé réservé aux membres de l'organisation.

Inventaire Matériel

Le parc est hétérogène, composé de :

  • Équipements terminaux : 1 Serveur, 4 PC fixes, 1 Tablette, 1 terminal sans fil.
  • Équipements d'interconnexion : 2 Routeurs (pour le routage entre réseaux), 3 Commutateurs (Switchs), 1 Point d'accès Wi-Fi, 1 Hub.

Rôles Identifiés

  • Serveur : SERVEUR-DIDESC
  • Clients : Tablet PC0, ATELIER-1, ATELIER-2, DIRECTION-1, DIRECTION-2

2. Tests de Connectivité

2.1 Liaison Locale (LAN)

Objectif : Vérifier la communication entre deux équipements du même réseau. Test : Ping depuis le PC DIRECTION-1 vers la tablette Tablet PC0. Résultat : Succès. Les équipements communiquent correctement au sein du même sous-réseau via les commutateurs.

2.2 Liaison Distante (Routage)

Objectif : Vérifier la communication entre deux équipements situés sur des réseaux différents. Test : Envoi d'un paquet (PDU) entre ATELIER-1 et SERVEUR-DIDESC. Observation : Échec initial. Diagnostic : Les routeurs ne connaissaient pas la route vers le réseau de destination. Solution : Configuration du protocole de routage RIP (Routing Information Protocol) pour échanger les tables de routage. Après un délai de convergence (le temps que les routeurs "cartographient" le réseau), la communication est devenue fonctionnelle.
